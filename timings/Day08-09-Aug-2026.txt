9 August learning Topics

AWS Shield
DDoS protection for AWS resources.
Protects services such as CloudFront, Route 53, and Elastic Load Balancing (ELB).
Shield Standard → Basic, automatic DDoS protection.
Shield Advanced → Stronger protection + visibility + AWS expert support + proactive protection + cost protection.
AWS WAF (Web Application Firewall)
Protects web applications from malicious HTTP/HTTPS traffic.
Helps block:
SQL Injection
XSS (Cross-Site Scripting)
Malicious IP addresses
Other common web attacks.
3-Tier Architecture
Presentation Tier → Web page, mobile application, UI.
Application / Business Logic Tier → APIs, backend services, business logic.
Data Tier → Databases and data storage.
Amazon GuardDuty
AWS threat detection service.
Continuously monitors AWS accounts and workloads for suspicious or malicious activity.
CVE & CVSS
CVE (Common Vulnerabilities and Exposures) → Identifies publicly known security vulnerabilities.
CVSS (Common Vulnerability Scoring System) → Gives a severity score to a vulnerability, generally 0–10.
Higher score = more serious vulnerability.
AWS Config
Monitors and records the configuration of AWS resources such as EC2, S3, RDS, etc.
Helps with compliance, auditing, and tracking configuration changes.
Amazon Macie
Security service focused mainly on Amazon S3.
Uses machine learning to discover and help protect sensitive data/PII in S3.
AWS KMS (Key Management Service)
Used to create and manage encryption keys.
Symmetric key → Same key is used for encryption and decryption.
Asymmetric key → Uses a public key + private key.
AWS Systems Manager (SSM)
Used to manage AWS servers and resources.
Can remotely access/manage EC2 instances without needing SSH in many scenarios.
Useful for patching, automation, parameter management, and remote commands.
Amazon RDS
Managed relational database service.
Supports databases such as MySQL, PostgreSQL, MariaDB, Oracle, and SQL Server.
Amazon Aurora
AWS-managed relational database engine compatible with MySQL and PostgreSQL.
Designed for high performance and availability.
Amazon DynamoDB
Fully managed NoSQL database.
Key-value and document database.
Designed for very high scalability and low-latency applications
