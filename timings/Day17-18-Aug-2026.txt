Day 17, 18 August 2026 : Helm Chart

What is Helm
Why Use Helm
  Simplifies Deployment
  Version Control
  Configuration Management
  Reusable and Shareable

Key Components of Helm
  Helm Client
  Helm Chart
  Helm Repository
  Helm Release

Helm Chart Structure
  Chart.yaml
  values.yaml
  templates/
  helpers.tpl
  charts/

helpers.tpl
  Define reusable template functions/snippets
  Avoid duplicate template code

Helm Repository Commands
  helm repo add
  helm repo update
  helm repo list
    Shows locally configured Helm repositories
    Does not show Helm releases installed in Kubernetes

Helm Installation
  helm install

Helm Release Management
  helm list -A
    Shows Helm releases installed in Kubernetes
  helm upgrade
  helm history
  helm rollback

Helm Revision and History
  Default maximum history: 10 revisions
  helm upgrade --history-max 20

Helm Repository vs Helm Release
  helm repo list : Configured Helm repositories
  helm list -A   : Installed Helm releases in Kubernetes

Helm Upgrade and Rollback Flow
  helm install  : Revision 1
  helm upgrade  : Revision 2
  helm upgrade  : Revision 3
  helm history  : Check release history
  helm rollback  : Roll back to previous revision
