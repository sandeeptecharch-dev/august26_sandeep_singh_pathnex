Kubernetes / Terraform Topics

1. Terraform State Lock
   - If Terraform state is locked, we can bypass the lock using:
     terraform apply -lock=false
   - Use carefully because bypassing the lock can cause state corruption
     if another Terraform process is running.

2. Terraform depends_on
   - Used when one resource/add-on must be created before another.
   - Example:
     resource "aws_eks_addon" "ebs-csi" {
       depends_on = [aws_eks_addon.pod_identity]
     }

3. Check Containers Inside a Kubernetes Pod
   - Command:
     kubectl get pod pod_name -n kube-system -o jsonpath='{.spec.containers[*].name}'

   - Example result:
     ebs-plugin csi-provisioner csi-attacher csi-snapshotter csi-resizer

   - Useful when a Pod contains multiple containers and you need to
     identify the correct container.

4. Check Logs of a Specific Container
   - Command:
     kubectl logs pod_name -c container_name -n kube-system

   - Example:
     kubectl logs pod_name -c csi-snapshotter -n kube-system

   - -c specifies which container's logs you want to see.

5. Describe a Kubernetes Pod
   - Command:
     kubectl describe pod pod_name -n namespace

   - Useful for debugging:
     * Pod events
     * Image pull errors
     * Scheduling problems
     * Volume problems
     * Container status
     * Readiness/liveness probe failures

6. Kubernetes Deployment YAML
   - Create Deployments for a 3-Tier Application:

     Frontend:
       Nginx

     Backend:
       HTTPD / Apache

     Database:
       MySQL

   - Understand:
     * Deployment
     * Pod
     * Container
     * Replica
     * Labels
     * Selectors
     * Container ports

7. Kubernetes Services
   - Understand why Services are required.
   - Service provides a stable network endpoint for Pods.
   - Main Service types:
     * ClusterIP
     * NodePort
     * LoadBalancer
     * ExternalName

8. Kubernetes Service Discovery
   - Understand how one application finds another application inside
     the Kubernetes cluster.
   - Kubernetes provides DNS-based service discovery.

   Example:

     Backend Service:
       backend-service

     Frontend can call:
       http://backend-service:8080

   - Understand:
     * Service name
     * ClusterIP
     * Kubernetes DNS
     * Namespace-based DNS
     * Service selector
     * Pod IP vs Service IP

      Frontend Service

     HTTPD/Apache

10. Important Concept

   Deployment = Creates and manages Pods

   Service = Provides stable access to Pods

   Service Discovery = Allows applications to find Services
                       using Kubernetes DNS
